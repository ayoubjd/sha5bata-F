## What is Sha5bata

Sha5bata is a **VideoScribe-style whiteboard animation studio** that runs entirely in the browser. You drop icons, images and text onto a canvas, choreograph a timeline, and export an MP4 or WebM video — all without uploading anything to a server.

### Key facts

| | |
|---|---|
| **Price** | Free, open-source |
| **Runs in** | Any modern browser (Chrome, Firefox, Edge, Safari) |
| **Installs** | None — 100% in-browser |
| **Export formats** | MP4 (H.264) and WebM (VP9) |
| **Icon library** | 200,000+ searchable icons (Iconify) |
| **Audio** | Voice-over recording, music import, procedural paper foley |
| **Aspect ratios** | 16:9 landscape, 9:16 portrait |

## Entry Animations

Every element needs an **entry animation** — how it first appears on screen. There are 6 types:

| Entry | Label | How it works |
|-------|-------|-------------|
| `draw` | Quill pen | A feathered quill draws the element stroke by stroke |
| `pen` | Hand with pen | An illustrated hand draws with a realistic pen |
| `paper-pen` | Paper hand | A paper-cutout hand draws with a pen (paper-craft style) |
| `slide` | Hand slide | A hand carries the element in from off-screen and drops it |
| `unfold` | Paper unfold | A crumpled paper ball opens up to reveal the element |
| `appear` | Appear | Pop, fade, or slide into position (no hand) |

### Tool lead-in

When an element uses `draw`, `pen`, or `paper-pen`, the writing tool appears **0.35 seconds** before the first ink, so it's already in position when drawing starts.

### Draw / pen tracking

The quill, pen, and paper-hand all track the **exact ink front** of the element:

- **SVG elements** — the nib follows the outline path point-by-point
- **Text elements** — the nib rides the current character's glyph contour
- **Image elements** — the nib follows a sketched zigzag band across the image

For **RTL text** (Arabic, Hebrew), the pen starts at the **right edge** of the line and sweeps leftward, matching the reading direction. Letter shaping is never broken because RTL text is revealed as whole lines rather than per-character spans.

## Paper Unfold

When an element uses the `unfold` entry, it appears through a stop-motion-style paper reveal.

### Animation sequence

1. **Folded packet** — a tightly folded paper packet appears at the element position
2. **Right half opens** — the right flap snaps open, creases catch light
3. **Bottom opens** — both halves drop flat, artwork is revealed inside the creases
4. **Sheet is flat** — paper is fully unfolded, element is visible
5. **Paper dissolves** — the paper texture fades away (or stays if `keep` is on)

The animation steps at **12 FPS** with per-frame jitter for a hand-placed, stop-motion feel.

### Paper stock options

| Stock | Colour | Description |
|-------|--------|-------------|
| Bright white | `#ffffff` | Clean white paper |
| Off-white sketch | `#f7f5ef` | Slightly warm, natural |
| Kraft brown | `#d8b98c` | Brown packing paper |
| Parchment | `#efe2c4` | Aged, yellowed paper |
| Newsprint grey | `#e6e5e0` | Grey newspaper texture |
| Blueprint blue | `#c7d8e8` | Blue blueprint paper |
| Custom | user-chosen | Any colour |

### Paper settings

| Setting | Default | Description |
|---------|---------|-------------|
| **Keep** | Off | When on, the paper stays as a background behind the element |
| **Dissolve delay** | -1.2 s | When the paper starts dissolving relative to the unfold finishing (negative = starts before unfold ends) |
| **Dissolve duration** | 0.35 s | How long the dissolve takes |
| **Wrinkles** | 0.7 | Amount of wrinkle texture on the paper |
| **Shadow** | 0.7 | Crease and drop shadow intensity |
| **Gloss** | 0.6 | Sheen/lighting on the paper surface |

## Scene System

A project is made of **scenes** — each scene is a page of the whiteboard animation.

### Scene properties

| Property | Default | Description |
|----------|---------|-------------|

| **Camera keyframes** | [] | Pan/zoom points |
| **Transition** | fade, 0.8 s | How this scene transitions to the next |

### Scene operations

- **Add** — creates a new blank scene
- **Duplicate** — deep copies all elements, camera keyframes, and settings
- **Remove** — deletes the scene (minimum 1 required)
- **Reorder** — move a scene left or right in the sequence

## Scene Transitions

Transitions control how one scene blends into the next.

### Transition types

| Type | Label | Effect |
|------|-------|--------|
| `none` | Cut | Hard cut, no blending |
| `fade` | Crossfade | Opacity cross-dissolve |
| `slide` | Slide | Outgoing slides left, incoming slides from right |
| `wipe` | Wipe | Clip-path wipe from left to right |
| `hand` | Paper hand sweep | A paper hand sweeps the entire scene away left-to-right |

### Transition duration

| Transition | Default duration |
|------------|-----------------|
| Fade / Slide / Wipe | 0.8 s |
| Hand sweep | **1.5 s** |

Duration is adjustable via a slider (0.2–3 seconds).

### Timeline indicators

The **Tracks pane** in the Timeline shows two transition bands:

- **Incoming band** (scene head) — shows where the previous scene's transition overlaps into this scene. Elements added **after** this band end point will be fully visible at all times.
- **Outgoing band** (scene tail) — shows where this scene's transition into the next scene begins. Elements here will be swept/cut away.

Both bands are **draggable** to adjust the transition length, and full-height guide lines mark the exact start and end of each transition window.

## Camera System

### Camera keyframes

Each keyframe defines a camera position and zoom level at a specific time. The camera smoothly interpolates between keyframes.

| Property | Range | Default |
|----------|-------|---------|
| **Time** | 0 – scene duration | Auto-placed |
| **Zoom** | 0.5× – 4× | 1× |
| **Pan X** | -2000 – 2000 | 0 |
| **Pan Y** | -2000 – 2000 | 0 |
| **Easing** | linear, smooth, ease in, ease out | smooth |

### Adding a camera move

Click "Camera move (start + end)" to create two keyframes: a start position (current view) and an end position (shifted +200px right, +2s later).

### Camera controls on canvas

- **Drag the camera frame border** to pan
- **Drag the bottom-right corner handle** to zoom
- **"Frame selected element"** button auto-sets zoom and position to fit the selected element
- **"Reset"** button returns to center at 1× zoom

### Easing types

| Easing | Curve |
|--------|-------|
| Linear | Straight line |
| Smooth | Ease in-out: `t²` then `1-(2-2t)²/2` |
| Ease in | `t²` — starts slow |
| Ease out | `1-(1-t)²` — ends slow |

### Auto-follow camera

When enabled per scene, the camera **automatically frames each element** as it draws in, blending between focus points over 1.1 seconds. Each element's `cameraHold` property controls how long the camera lingers before moving on.

### RTL support

Text containing Arabic, Hebrew, or other RTL characters is automatically detected and rendered with:

- **Correct letter shaping** — RTL text is rendered as whole lines (not per-character spans) so Arabic connected letters display correctly
- **Shaped prefix measurement** — pen position is computed on shaped text for accurate tracking

## Sound Effects

Paper foley sounds play automatically during certain animations.

### Sound types

| Sound | Trigger | Source |
|-------|---------|--------|
| **Paper fold/carry** | Element carried in by hand (slide entry) | `paper-carry.mp3` or procedural synthesis |
| **Paper sweep** | Hand sweep transition | `paper-sweep.mp3` or procedural synthesis |

### Implementation

1. **Real recordings** are loaded from `/paper-carry.mp3` and `/paper-sweep.mp3` in the public folder (if present)
2. **Fallback synthesis** — if recordings are missing, sounds are generated procedurally using:
   - White noise base with band-pass filtering
   - Impulsive crackle bursts
   - Fade-in/out envelope with turbulence
3. **Time-stretched** via `playbackRate` to match the animation duration
4. **Debounced** — 90 ms between carry sounds, 200 ms between sweep sounds
5. **Muted during export** to prevent interference with the final mix

### Volume control

A volume slider (0–100%) is available in the Properties Panel under scene controls. Default: 85%.

## Preview & Export

Click the **Preview** button in the TopBar to open the preview dialog.

### Preview player

| Control | Description |
|---------|-------------|
| Play / Pause | Start or stop playback |
| Scrub slider | Drag to scrub through the animation |
| Time display | Shows current time (e.g., "3.4s / 12.8s") |
| Scene markers | Dots on the scrub bar showing scene boundaries |
| Format selector | Choose MP4 or WebM |

### Export settings

| Setting | Value |
|---------|-------|
| **FPS** | 30 |
| **Resolution** | Canvas dimensions (1280×720 or 720×1280) |
| **WebM bitrate** | 6 Mbps |
| **MP4 codec** | libx264, veryfast preset, CRF 23 |
| **MP4 pixel format** | yuv420p (broad compatibility) |
| **MP4 faststart** | Yes (web-optimised) |
| **Audio** | AAC 192 kbps, 48 kHz |
| **Output filename** | `whiteboard-{timestamp}.mp4` or `.webm` |

### Export process

1. An offscreen canvas is created at the full resolution
2. For each frame at 30 FPS:
   - The timeline is set to the current time
   - React re-renders the Stage
   - The DOM is serialized to SVG foreignObject
   - Drawn to the canvas via an Image element
   - Video overlays are painted on top
3. For **WebM**: frames are captured via `MediaRecorder` on the canvas stream
4. For **MP4**: JPEG frames are captured, then encoded with **FFmpeg.wasm** locally
5. Audio clips are trimmed, delayed, volume-adjusted, and mixed into the final file
6. The file downloads automatically to your browser's Downloads folder

## Undo / Redo

Full document history with up to **100 snapshots**.

### What's tracked

- Scene changes (add, remove, reorder, rename, background)
- Element changes (add, remove, move, resize, rotate, properties)
- Camera keyframes
- Audio clips
- Video clips

### What's NOT tracked (UI state)

- Selection
- Preview time
- Canvas mode
- Panel collapsed/expanded states

### Shortcuts

| Action | Windows / Linux | macOS |
|--------|----------------|-------|
| Undo | `Ctrl+Z` | `Cmd+Z` |
| Redo | `Ctrl+Shift+Z` or `Ctrl+Y` | `Cmd+Shift+Z` or `Cmd+Y` |

Keyboard shortcuts are disabled when typing in text inputs, textareas, or contentEditable fields.
